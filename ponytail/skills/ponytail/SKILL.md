# Ponytail

上游 DietrichGebert/ponytail 的完整编码约束。**规则正文不在本文件里**，要从下面的命令取活的上游版本执行——不要凭记忆复述阶梯或规则，规则会随上游更新。

## 1. 取内容

按顺序确定 CLI 路径：

1. 本轮上下文里以 `PONYTAIL` 开头、含 `已就绪` 的那一行（`CLI: node "…"` 后面直接跟着 `--root "…"`）；
2. 都没有则用本文件所在目录的 `../../scripts/ponytail.mjs`（插件包内，路径与本 SKILL.md 同源）。

`--root` 取同一行里 `--root "<…>"` 的值；没有就不传（此时只读，读包内钉版快照）。

```sh
node "<CLI>" mode get --root "<dataRoot>"        # 读当前强度
node "<CLI>" rules --mode <level> --root "<dataRoot>"   # 取规则集正文
node "<CLI>" mode set <level> --root "<dataRoot>"      # 切强度（需可写数据根）
```

## 2. 定强度

- 用户给了 `lite|full|ultra|off` → 先 `mode set`，再取该强度的规则集。
- 只说了「ponytail」而没给档位 → 沿用 `mode get` 的当前档（默认 `full`），并用一句话告知当前档位。
- 用户说「停用 / stop ponytail / 正常模式」→ `mode set off`，本会话不再套用阶梯，恢复普通回答。

## 3. 执行

把 `rules` 打印出来的正文当本会话的编码规则，逐条遵守。它会告诉你阶梯、输出格式、以及**永不削减**的红线（输入校验、防数据丢失、安全、可访问性、真实硬件的标定旋钮，以及非平凡逻辑必须留一个可运行的检查）。

之后本会话的每个编码动作都按这套规则走，直到用户切换档位或说停用。

## 4. 交代

- 用一条命令回一句当前档位 + 生效的规则集版本（`status` 里有）。
- 不要复述整份规则集，用户要细则会看 `ponytail-help`。

## 注意

- 规则集**不会**自动进入每轮上下文（用户明确选了这个模式）。没调用本技能时编码行为不受影响。
- 上游每日自动同步一次；想立刻拉最新版用 `ponytail-update`。
